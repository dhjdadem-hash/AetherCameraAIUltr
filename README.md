Aether Camera AI Ultra

Version: 2.1.0
Build: 3
Platform: Android
Language: Kotlin

A modern Android camera application with a Liquid Glass-inspired interface, camera controls, photo capture, video recording, and image enhancement.

Features

- Live camera preview
- Photo capture
- Video recording
- Zoom controls
- Flash controls
- Camera selection when supported by the device
- Local AI Color-style image enhancement
- Photo and video gallery
- Runtime permission handling

Device Compatibility

Device: PLD110
System version: 16.0.5.1001

Camera capabilities depend on the phone hardware, Android camera drivers, and manufacturer restrictions.

Build APK with GitHub Actions

1. Upload the complete Android project to this repository.
2. Open the Actions tab.
3. Run the Android APK build workflow.
4. Wait for the build to finish.
5. If the build succeeds, open the workflow run and download the APK from Artifacts.

Important

This project is under development. Build success and device compatibility must be tested. Advanced features such as 8K recording, 120x zoom, RAW capture, and independent access to secondary cameras are not guaranteed.
